## Описание проекта

Я разработал `StreamStats` — консольную программу для анализа событий из файлов CSV и JSONL

Программа обрабатывает входные данные, собирает статистику и сохраняет результат в отчёт
### Возможности программы

- Чтение файлов CSV и JSONL

- Обработка нескольких входных файлов за один запуск

- Подсчёт общего количества событий и количества событий каждого уровня

- Подсчёт событий по источникам

- Поиск топ-5 источников с наибольшим количеством ошибок

- Определение времени первого и последнего события

- Пропуск некорректных строк с помощью `--skip-invalid`

- Сохранение отчётов в JSON и CSV

- Фильтрация событий по времени, уровню и источнику через `filters.py`

## Команды запуска программы

### Анализ CSV

```
python -m streamstats analyze events.csv --format csv
```

### Анализ JSONL

```
python -m streamstats analyze events.jsonl --format jsonl
```

### Обработка нескольких файлов

```
python -m streamstats analyze events1.csv events2.csv --format csv --output report.json
```

### Пропуск некорректных строк

```
python -m streamstats analyze events.csv --format csv --skip-invalid
```

### Сохранение отчёта в CSV

```
python -m streamstats analyze events.csv --format csv --output report.csv --csv
```

По умолчанию отчёт сохраняется в файл `report.json`

Для просмотра справки используем команду

```
python -m streamstats --help
```

## Формат входных данных

Каждое событие должно содержать четыре поля

|Поле|Описание|
|---|---|
|`timestamp`|Дата и время события с часовым поясом|
|`level`|Уровень события|
|`source`|Источник события|
|`message`|Текст сообщения|

Поддерживаемые уровни событий:

`DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`

## Алгоритм работы программы

1. Передаём программе один или несколько входных файлов и указываем формат данных

2. Программа проверяет  корректность входных файлы для сохранения отчёта

3. Парсер читает события и проверяет их корректность

4. Если включён `--skip-invalid`, некорректные строки пропускаются

5. Анализатор создает статистику

6. Получаем готовый отчёт в JSON или CSV


## Фильтрация событий

В `filters.py` я реализовал три функции для фильтрации событий

|Функция|Назначение|
|---|---|
|`filter_by_time()`|Отбирает события в заданном временном промежутке|
|`filter_by_level()`|Отбирает события указанного уровня|
|`filter_by_source()`|Отбирает события по источнику|

Функции используют `yield` (так как ленивые фильтры надо было сделать)

## Обработка ошибок

Программа обрабатывает основные ошибки при работе с файлами и событиями

- Входные файлы не указаны
- Файл не найден или указан неправильный путь
- Входной файл совпадает с файлом отчёта
- Указан неподдерживаемый формат
- Неверная временная метка
- Некорректное событие
- Выходной файл должен быть json или csv

При включённом `--skip-invalid` некорректные строки пропускаются, а их количество добавляется в отчёт

При обработке предусмотренных ошибок программа выводит сообщение в `stderr` и завершается с кодом `2`

## Тестирование

Для  проверки используем `pytest`

```

```

Что бы проверить:

